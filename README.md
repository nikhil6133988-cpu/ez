# ezlab-form

Simple React + Vite + Tailwind contact form demo (real API POST).

To run:
1. unzip and open folder `ezlab-form`
2. run `npm install`
3. run `npm run dev`
4. Open the local URL shown by Vite (e.g. http://localhost:5173)

Notes:
- The form posts to the real API: https://vernanbackend.ezlab.in/api/contact-us/
- Frontend validation: all fields required + email format
- On success the UI shows: "Form Submitted ✅"
